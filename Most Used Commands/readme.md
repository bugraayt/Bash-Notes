#man

The first command I'll introduce will help you understand all the other commands.

Every time I don't know how to use a command, I type man <command> to get the manual

man whoami



#clear

Type clear to clear all the previous commands that were run in the current terminal.

!!!Type "clear -x" if you want to see the previous work by scrolling up.!!!




#pwd

It will print the current folder path.

#cd

You can move into it using the cd command. cd means change directory. 

You can also use absolute paths, which start from the root folder /:

cd /etc



#mkdir

You create folders using the mkdir command



#rmdir

you can delete a folder using rmdir



#touch

You can create an empty file by using touch command

!!!If the file exists it opens it in edit mode !!!



#rm

You can remove files or directories
use "rm -v" to see each step you did while removing files
use "rm -r" to remove directories and their contents
